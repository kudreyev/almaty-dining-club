# WhatsApp Utility: доступ после оплаты + PWA

Текущий шаблон `TWILIO_CONTENT_SID_ACCESS` уже утверждён в Meta.
Чтобы добавить строку про установку PWA, нужна **новая версия** шаблона
и повторное утверждение в Twilio Content / Meta.

## Переменные (как в коде `access-messaging.ts`)

| Var | Значение |
|---|---|
| `{{1}}` | Ссылка «ваш доступ» (`getAccessUrl()` — каталог) |
| `{{2}}` | Дата следующего списания |
| `{{3}}` | Ссылка на кабинет для установки PWA (`getPwaInstallInviteUrl()` → `/app/me?utm_source=whatsapp_pwa`) |

## Текст новой версии (RU)

```
Ваш доступ kudaclub открыт: {{1}}
Следующее списание: {{2}}.

Добавьте kudaclub на главный экран — код будет всегда под рукой: {{3}}
```

(При необходимости подгони формулировку под лимиты Utility-категории Meta;
смысл: доступ + дата + призыв установить PWA со ссылкой на кабинет.)

## Что сделать вручную

1. Twilio Console → Content Template Builder → создать **новую** версию
   ACCESS-шаблона с тремя переменными и текстом выше.
2. Отправить на approval в Meta.
3. После approve заменить `TWILIO_CONTENT_SID_ACCESS` в env на новый ContentSid.
4. Пока старый SID в env — Twilio может игнорировать лишнюю `{{3}}`,
   либо шаблон упадёт, если Meta строго валидирует; лучше не деплоить
   новый SID, пока шаблон не одобрен.

**Действие для тебя:** переутвердить этот текст в Twilio-консоли (Meta approval).
