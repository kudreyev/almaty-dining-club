# Подключение подписки TipTop Pay на kudaclub.kz

## Как это работает

Пользователь нажимает «Оформить подписку» → открывается виджет TipTop Pay → оплачивает первый месяц картой. Вместе с оплатой создаётся подписка: TipTop Pay сам списывает 1 990 ₸ каждый месяц, сам делает повторные попытки при нехватке средств и напоминает пользователю о списании. Ваш сервер узнаёт о каждой оплате и смене статуса подписки через вебхуки и открывает/закрывает доступ.

Источник правды — только серверные вебхуки, не коллбэк виджета на фронте.

## Файлы

| Файл | Назначение |
|---|---|
| `components/SubscribeButton.tsx` | Кнопка оплаты, запускает виджет с параметрами подписки |
| `app/api/tiptoppay/pay/route.ts` | Вебхук Pay — каждая успешная оплата (первая и рекуррентные) |
| `app/api/tiptoppay/recurrent/route.ts` | Вебхук Recurrent — смена статуса подписки |
| `lib/tiptoppay.ts` | Проверка HMAC + API (отмена/поиск/изменение подписок) |
| `.env.example` | Переменные окружения |

## Шаги внедрения

1. **Env.** Скопируйте значения из `.env.example` в `.env.local` и в переменные окружения продакшена (Vercel и т.п.). Public ID и API Secret — в личном кабинете merchant.tiptoppay.kz.
2. **Код.** Скопируйте файлы в проект (пути соответствуют Next.js App Router). В обоих роутах замените `TODO` на запись в вашу БД. Минимально нужны поля у пользователя: `subscriptionStatus`, `subscriptionId`, `paidUntil`.
3. **Личный кабинет TipTop Pay.** В настройках уведомлений укажите:
   - Pay: `https://kudaclub.kz/api/tiptoppay/pay`
   - Recurrent: `https://kudaclub.kz/api/tiptoppay/recurrent`
   - Формат: POST, кодировка UTF-8. HMAC включён по умолчанию — сверьте название заголовка (`Content-HMAC`) с разделом «Уведомления» в [документации](https://developers.tiptoppay.kz/#uvedomleniya).
4. **Кнопка на сайте.** На странице `/pricing` замените ссылку на WhatsApp на `<SubscribeButton userId={user.id} email={user.email} />`. Кнопка должна быть доступна только залогиненным (нужен `userId` для привязки подписки).
5. **Отмена подписки.** В личном кабинете пользователя добавьте кнопку «Отменить подписку», которая вызывает `cancelSubscription(subscriptionId)` из `lib/tiptoppay.ts`. Доступ оставляйте до конца оплаченного периода (`paidUntil`).
6. **Тест.** Используйте тестовый терминал и тестовые карты из раздела «Тестирование» документации. Проверьте: оплату, приход Pay-вебхука, активацию доступа, отмену подписки. Реальных списаний в тестовом режиме нет (`TestMode = 1` в вебхуке).
7. **Продакшен.** Замените тестовый Public ID на боевой, проведите платёж на 1 990 ₸ со своей карты, убедитесь, что подписка появилась в ЛК, затем отмените её.

## Что нужно проверить по документации

Формат TipTop Pay совместим с CloudPayments, но точные имена полей вебхуков (Pay: `SubscriptionId`, `AccountId`, `Status`; Recurrent: `Id`, `Status`, `NextTransactionDate`) сверьте с разделом «Уведомления» на developers.tiptoppay.kz — раздел не попал в мою выгрузку целиком. Если что-то не совпадёт, поправить нужно только имена полей в двух роутах.
